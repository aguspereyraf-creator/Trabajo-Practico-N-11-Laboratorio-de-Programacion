# Trabajo-Practico-N-11-Laboratorio-de-Programacion

## Uso de Inteligencia Artificial

Durante el desarrollo del proyecto utilicé inteligencia artificial como herramienta de apoyo para programar la lógica en JavaScript.

Le expliqué a la IA la idea del juego, indicando que debía controlar una computadora con el teclado, atrapar figuras de hielo, sumar puntos, perder vidas y establecer condiciones de victoria y derrota.

También le pedí que el código fuera sencillo y acorde a los conocimientos vistos en clase, y que explicara las partes principales para poder comprender cómo funciona el programa.
